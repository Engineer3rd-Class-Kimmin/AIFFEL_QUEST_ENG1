## 회고

Advanced RAG는 기법을 많이 붙이는 것이 목적이 아니라, 실패 원인을 검색 범위·문서 순위·답변 검증 중 어디에서 찾을지 정하고 필요한 모듈만 조합하는 과정임을 확인할 수 있었다. 특히 RAGAS의 Faithfulness, Answer Relevance, Context Precision, Context Recall을 함께 보아야 검색 개선이 실제 답변 개선으로 이어졌는지 판단할 수 있다. 다음에는 비용과 지연시간도 함께 기록해 품질 대비 효율을 비교하면 실서비스 관점의 실험이 될 것이다.
